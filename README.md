## Genealogy Map

A simple map displaying the locations that my grandfather's family lived in New York City 1900-1950. I got the genealogy bug a few years ago, and every so often have thought that it would be interesting to visualize all of the different addresses that I was seeing in the historical records.

It wasn't until I took [Chris Whong](https://wagner.nyu.edu/community/faculty/christopher-whong)'s Interactive Web Mapping course that I really got the technical tools to make a nice-quality map, though. This repo contains code using MapboxGL for a simple webpage with the geneaological map.
